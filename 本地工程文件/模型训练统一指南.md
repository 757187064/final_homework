## 3. 准备 Kaggle Notebook

1. 打开 Kaggle。
2. 新建 Notebook。
3. 右侧 `Add data` 添加 Severstal 数据集。
4. 打开 GPU：

```text
Notebook Settings -> Accelerator -> GPU
```

5. 确认 Notebook 能看到数据目录。常见路径：

```text
/kaggle/input/severstal-steel-defect-detection/
```

可以在 Notebook 里运行：

```python
import os
print(os.listdir("/kaggle/input"))
```

## 4. 把项目代码放到 Kaggle

推荐两种方式，选一种就行。

### 方式 A：从 GitHub 拉代码

在 Kaggle Notebook 里运行：

```bash
git clone https://github.com/757187064/final_homework.git
cd final_homework/本地工程文件/训练与推理代码
```

如果 GitHub 网络不稳定，用方式 B。

### 方式 B：上传为 Kaggle Dataset

把整个项目压缩上传到 Kaggle Dataset，然后在 Notebook 中 Add data。

进入代码目录时注意实际路径，例如：

```bash
cd /kaggle/input/你的代码数据集名/本地工程文件/训练与推理代码
```

如果该目录只读，需要复制到工作目录：

```bash
cp -r /kaggle/input/你的代码数据集名 /kaggle/working/final_homework
cd /kaggle/working/final_homework/本地工程文件/训练与推理代码
```

## 7. 统一 train.csv 格式

项目标准格式是：

```text
ImageId_ClassId,EncodedPixels
```

如果 Kaggle 数据集中的 `train.csv` 已经是这个格式，跳过本步。

如果是：

```text
ImageId,ClassId,EncodedPixels
```

运行：

```bash
python scripts/normalize_train_csv.py \
  --input /kaggle/input/severstal-steel-defect-detection/train.csv \
  --output /kaggle/working/train_standard.csv
```

然后把配置里的：

```yaml
train_csv: train.csv
```

改成绝对路径：

```yaml
train_csv: /kaggle/working/train_standard.csv
```

当前代码也兼容两种格式，但统一成标准格式更便于组内沟通。

## 8. 先跑 Debug

运行：

```bash
python scripts/train.py --config configs/debug.yaml
```

成功标志：

```text
数据统计：total=..., defect=..., empty=...
使用设备：cuda
epoch=1 train_loss=... val_loss=... val_dice=...
最佳模型已保存：outputs/debug_smoke_test/best_model.pth
```

如果 `使用设备` 不是 `cuda`，说明没有开 GPU，先去 Notebook Settings 打开 GPU。

Debug 失败时，把完整报错发出来，不要继续 Baseline。

## 9. 跑 Baseline

Debug 通过后运行：

```bash
python scripts/train.py --config configs/baseline.yaml
```

如果出现权重下载失败：

把 `configs/baseline.yaml` 中：

```yaml
encoder_weights: imagenet
```

改成：

```yaml
encoder_weights: null
```

如果显存不足：

把：

```yaml
batch_size: 8
```

改成：

```yaml
batch_size: 4
```

或者更小。

## 10. 生成 submission.csv

Baseline 训练完成后运行：

```bash
python scripts/infer.py \
  --config configs/baseline.yaml \
  --checkpoint outputs/baseline_unet_resnet34/best_model.pth \
  --output outputs/baseline_unet_resnet34/submission.csv
```

同时复制一份到 Kaggle 标准输出位置：

```bash
cp outputs/baseline_unet_resnet34/submission.csv /kaggle/working/submission.csv
```

检查是否存在：

```python
import os
print(os.path.exists("/kaggle/working/submission.csv"))
print(os.listdir("/kaggle/working"))
```

## 13. Baseline 后再做什么

Baseline 有结果后，再跑：

```bash
python scripts/train.py --config configs/full_pipeline.yaml
python scripts/train.py --config configs/ablations/no_augmentation.yaml
python scripts/train.py --config configs/ablations/no_scheduler.yaml
```

这些结果给 04 写消融实验。

基于 02 的数据分析，重点观察：

- Class 2 样本很少，是否漏检严重。
- Class 3 样本很多，模型是否偏向多数类。
- 数据增强去掉后 Dice 是否下降。
- 学习率调度去掉后收敛是否变差。

## 14. 常见报错速查

### 找不到 train.csv

检查配置里的 `data.root` 和 `train_csv`。

### 找不到 test_images

检查 Kaggle 数据路径下是否有 `test_images/`。

### 生成了 submission 但 Kaggle 找不到

执行：

```bash
cp outputs/baseline_unet_resnet34/submission.csv /kaggle/working/submission.csv
```

### 训练不是 cuda

去 Notebook Settings 开 GPU。

### 权重下载失败

把 `encoder_weights` 改成 `null`。

### 显存不足

减小 `batch_size`。
