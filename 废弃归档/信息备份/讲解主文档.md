# 组会讲解主文档

> 用途：你现在拿着这份文档给三位队友讲。它是“现场讲解顺序”，不是技术细节全集。讲完后让大家进入各自文件夹看自己的工作指导。

## 你要先告诉大家的结论

我们已经把项目整理成四个工作包，每个人拿一个包推进：

| 文件夹 | 负责人 | 核心目标 |
|---|---|---|
| `01_项目统筹与提交/` | 你 | 控制进度、提交材料、统一口径、记录智能体协作 |
| `02_数据分析与可视化/` | 队友 A | 负责数据到 Mask 的全过程：RLE、数据表整理、类别分布、样本可视化、数据增强解释 |
| `03_模型训练与代码实现/` | 队友 B | 负责模型训练到提交：U-Net、loss/metric、checkpoint、submission 和调参 |
| `04_实验汇报与答辩/` | 队友 C | 管消融实验表、报告、PPT、答辩材料 |

## 0-3 分钟：开场

可以照着说：

```text
我们这次做 Kaggle 的 Severstal 钢板缺陷检测。它不是简单图片分类，而是要预测钢板表面 4 类缺陷的像素级 Mask，所以属于语义分割任务。

我已经先把项目样板搭好了，包括代码、配置、报告模板、PPT 大纲、答辩题库和分工说明。
今天的目标是让大家知道项目怎么做，然后每个人认领一个明确工作包。
```

强调目标：

```text
我们不是盲目冲排行榜，而是做课程高分稳妥版：流程完整、代码能跑、消融实验清楚、报告和答辩有证据。
```

## 3-8 分钟：讲清赛题

只讲 4 个关键词：

| 关键词 | 解释 |
|---|---|
| 钢板缺陷 | 图像里可能有 4 类表面缺陷，也可能没有缺陷。 |
| 语义分割 | 模型要输出缺陷在哪些像素上，而不只是判断有没有缺陷。 |
| RLE | Kaggle 用 RLE 字符串保存 Mask，代码里已经写了编码/解码。 |
| Dice | 评价预测 Mask 和真实 Mask 的重叠程度，越高越好。 |

可以这样补一句：

```text
这个题最容易出错的是 RLE 格式和提交格式，所以代码里把 RLE 单独做成模块，并提供了测试。
```

## 8-15 分钟：展示四个工作包

打开文件夹给大家看：

### 01 项目统筹与提交

你负责。里面有课程要求、评分标准、选题报告草稿、任务看板、提交检查表。

你要说：

```text
我会负责总进度、最终合并、提交材料和智能体使用记录。大家每次实验或文档结果都要同步给我。
```

### 02 数据分析与可视化

队友 A 负责。目标不只是画图，而是讲清“原始数据如何变成模型可训练的 Mask”。

你要说：

```text
这部分重点不是训练模型，而是负责数据管道：图片格式、train.csv、RLE 解码、4 通道 Mask、类别不平衡、样本可视化和数据增强解释。
也就是说，2 号同学负责“数据到 Mask”，3 号同学负责“Mask 到模型预测和提交”。
```

### 03 模型训练与代码实现

队友 B 负责。里面有训练代码、推理代码、配置和依赖，但不需要独自承担数据解释部分。

你要说：

```text
正式训练放 Kaggle GPU，本地只做 debug。3 号同学重点负责跑 Baseline、保存训练结果、生成 submission，再配合 4 号同学完成消融实验。
```

### 04 实验汇报与答辩

队友 C 负责。里面有消融实验计划、资源记录、报告草稿、PPT 大纲、答辩题库。

你要说：

```text
这部分负责把实验结果变成老师能看懂的材料：表格、曲线、结论、失败反思、PPT 和答辩。
```

## 15-22 分钟：现场分工

建议直接这样分：

| 成员 | 工作包 | 今天会后第一件事 |
|---|---|---|
| 你 | `01_项目统筹与提交/` | 补全队名、组员、选题报告，并维护任务看板 |
| 队友 A | `02_数据分析与可视化/` | 阅读数据分析和 RLE 数据管道说明，准备跑数据分析脚本 |
| 队友 B | `03_模型训练与代码实现/` | 阅读模型训练指导，准备 Kaggle Notebook 环境并跑 Baseline |
| 队友 C | `04_实验汇报与答辩/` | 阅读实验汇报指导，准备消融表和 PPT 初稿 |

现场问每个人：

```text
你能接受这个方向吗？
你今天/明天能交出第一个什么结果？
你需要别人提供什么？
```

## 22-30 分钟：确认会后动作

会后 24 小时内要完成：

| 负责人 | 交付 |
|---|---|
| 你 | 选题报告信息补全，任务看板填好负责人和截止时间 |
| 队友 A | 数据分析图、RLE/数据管道解释初稿 |
| 队友 B | Kaggle 环境跑通，至少完成 debug 或 Baseline 启动 |

最后收束可以说：

```text

每个人的产出都要能直接放进报告或 PPT。
```

## 现场不要忘记强调

- 不要上传 Kaggle 大数据到课程仓库。
- 不要每个人都改同一份核心代码。
- 每次实验必须记录配置、平台、耗时、Dice、Kaggle 分数。
- MacBook 不跑完整训练，正式训练用 Kaggle GPU。
- 智能体使用过程要保留 Prompt 迭代记录。
