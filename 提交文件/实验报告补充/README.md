# 实验报告补充文件说明

本文件夹保存实验报告正文和报告支撑材料。按照最新整理要求，本文件夹内部不再继续分子文件夹，所有文件均以单个文件形式平铺保存。

## 正式报告文件

| 文件 | 作用 |
|---|---|
| `实验报告.md` | Markdown 格式实验报告，用于课程 Gitee 提交 |
| `实验报告.pdf` | 当前导出的 PDF，可用于打印或备份 |

## 数据分析图表

| 文件前缀 | 作用 |
|---|---|
| `图表素材_类别分布图.png` | 展示 4 类缺陷的数据分布 |
| `图表素材_样本Mask叠加图.png` | 展示钢板图像与缺陷 Mask 叠加效果 |
| `图表素材_数据分析补充图_*.png` | 02 号同学补充的按类别样本图、原图和拼接图 |
| `图表素材_*.csv` | 图表对应的统计数据 |

| 文件前缀 | 作用 |
