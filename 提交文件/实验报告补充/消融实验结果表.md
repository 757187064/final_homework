# 消融实验记录表

本表用于最终报告和 PPT 的消融实验页。所有正式实验结果均需区分“本地最佳 Val Dice”和“Kaggle leaderboard 分数”，两类指标来源不同，不能直接混写为同一种得分。

| 实验编号 | 配置文件 | 核心变量 | 本地最佳 Val Dice | Kaggle Private | Kaggle Public | 训练平台 | 结论 |
|---|---|---|---:|---:|---:|---|---|
| E0 | `configs_baseline.yaml` | Baseline：U-Net + ResNet34 + light aug + scheduler | 0.6450 | 0.84233 | 0.80548 | Kaggle GPU | Public 最优，作为稳定备选 |
| E1 | `configs_full_pipeline.yaml` | 更强增强 + 更长训练 + Dice 权重更高 | 0.6613 | 0.74355 | 0.73140 | Kaggle GPU | 本地验证较好，但 Kaggle 分数明显偏低，作为反思案例 |
| E2 | `configs_ablation_no_augmentation.yaml` | 去掉数据增强 | 0.6373 | 0.84558 | 0.80372 | Kaggle GPU | Private 最优，作为最终主结果候选 |
| E3 | `configs_ablation_no_scheduler.yaml` | 去掉学习率调度 | 0.6281 | 0.83704 | 0.79335 | Kaggle GPU | 分数略低，可说明 scheduler 有一定作用 |

## 记录规范

- 每次实验保存配置文件、`history.csv`、`history.png`、最佳模型和预测可视化。
- 只改一个关键变量，避免无法解释提升来自哪里。
- 如果实验失败，也记录失败原因，例如显存不足、过拟合、训练不稳定、提交格式错误。

## 报告可用结论

- 最终口径：No Augmentation 是 Private Score 最优主结果，Baseline 是 Public Score 最优稳定备选。
- 数据增强贡献：E2 去掉增强后 Kaggle 分数反而高于 Full Pipeline，说明当前强增强可能破坏钢板缺陷的细长纹理特征。
- 学习率调度贡献：E3 去掉 scheduler 后 Public/Private 均低于 Baseline，可说明调度策略对稳定收敛有帮助。
- Full Pipeline 反思：E1 本地 Val Dice 最高但 Kaggle 分数最低，最终报告应解释验证集与 leaderboard 差异，不应写成最终最佳模型。
- 资源效率：记录 Kaggle GPU 使用时长，说明本地只做 Debug，正式训练使用免费/低成本 GPU。
