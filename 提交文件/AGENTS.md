# AGENTS.md

本文件记录本项目中智能体工具的使用方式、协作边界和可追溯材料。项目为 Kaggle Severstal 钢板缺陷检测，最终提交目录采用课程要求的结构：根部说明文件、`代码/`、`实验报告补充/`。

## 智能体使用原则

1. 智能体用于辅助项目统筹、代码检查、实验解释、报告整理和格式核对。
2. 不伪造实验结果、Kaggle 排名、截图证据或博客链接。
3. 涉及费用、GPU 时长、Prompt 证据时，优先保守记录真实可确认信息。
4. 代码与报告口径必须保持一致，特别是 Val Dice、Public Score、Private Score 不混用。
5. 最终提交前由 01 角色统一检查文件结构、报告图片、README、依赖和 Gitee 上传状态。
