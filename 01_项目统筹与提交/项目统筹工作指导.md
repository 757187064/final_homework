# 项目统筹工作指导

> 负责人：你。目标是把全组工作变成可提交、可讲解、可评分的最终成果。

## 你负责什么

- 维护总进度和任务看板。
- 补全选题报告、队伍信息、组员信息。
- 汇总所有实验结果、图表、PPT、报告段落。
- 记录智能体使用过程和 Prompt 迭代。
- 最终检查课程评分点是否全部覆盖。

## 你要重点看的文件

| 文件 | 用途 |
|---|---|
| `期末汇报大作业要求.md` | 所有提交要求和时间节点 |
| `评分标准.md` | 最终得分依据 |
| `现场打分表.md` | 老师现场如何打分 |
| `实验报告模板.md` | 最终报告正式模板 |
| `topic_info_report_draft.md` | 选题信息报告草稿 |
| `grading_coverage_checklist.md` | 最终提交前自查 |
| `team_task_board.md` | 组内任务看板 |
| `collaboration_guide.md` | 四人协作规则 |
| `AGENTS.md` | 智能体协作规则，可写进报告 |

## 今天优先做

1. 在 `topic_info_report_draft.md` 中补全队名、组长、组员姓名学号。
2. 打开 `team_task_board.md`，把四个人的负责人和截止时间填上。
3. 把 `讲解主文档.md` 发给队友，按四个工作包分配任务。
4. 建一个共享记录方式，记录每个人每天完成了什么。

## 你每次收队友结果时要检查

- 是否有明确文件输出。
- 是否能直接放进报告或 PPT。
- 是否写清实验配置、平台、耗时和指标。
- 是否有截图、曲线、表格或可视化作为证据。

## 最终你要合并的内容

| 来源 | 合并到哪里 |
|---|---|
| 数据负责人给的数据图和分析文字 | 实验报告 1.3/1.4，PPT 数据分析页 |
| 模型负责人给的训练曲线和分数 | 实验报告方法和结果，PPT 结果页 |
| 实验汇报负责人给的消融表和答辩题 | 实验报告消融章节，PPT 和答辩准备 |
| 智能体使用记录 | 实验报告第三章 |

## 截止前自查

用 `grading_coverage_checklist.md` 逐项检查：

- 代码仓库是否完整。
- README/指导文件是否清楚。
- 实验报告是否补齐真实结果。
- PPT 是否导出 PDF。
- 纸质报告是否准备 4 份。
- 智能体使用记录是否有真实 Prompt 迭代。
- 组员贡献是否具体。
