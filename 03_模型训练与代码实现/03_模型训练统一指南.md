# 03 模型训练统一指南

> 你现在是 03。当前唯一目标：基于 02 的数据分析结果，跑通训练和 Kaggle 提交。旧版 03 说明已归档，不再作为执行入口。

## 你现在要做什么

一句话：

```text
把数据整理成标准 train.csv，跑通 debug，跑 baseline，生成 submission，记录分数和训练产物。
```

不要先做复杂调参。第一轮只追求可运行、可复现、有结果。

## 第 0 步：进入目录

```bash
cd 03_模型训练与代码实现
```

## 第 1 步：准备数据

推荐结构：

```text
data/raw/
├── train.csv
├── sample_submission.csv
├── train_images/
└── test_images/
```

如果在 Kaggle Notebook 中，数据通常在：

```text
/kaggle/input/severstal-steel-defect-detection/
```

此时把配置文件里的：

```yaml
data:
  root: data/raw
```

改为：

```yaml
data:
  root: /kaggle/input/severstal-steel-defect-detection
```

## 第 2 步：统一 train.csv 格式

项目统一使用标准格式：

```text
ImageId_ClassId,EncodedPixels
```

如果你的 `train.csv` 已经是这个格式，直接进入下一步。

如果你的 `train.csv` 是：

```text
ImageId,ClassId,EncodedPixels
```

运行：

```bash
python scripts/normalize_train_csv.py \
  --input data/raw/train.csv \
  --output data/raw/train_standard.csv
```

然后把所有要运行的配置文件中：

```yaml
train_csv: train.csv
```

改成：

```yaml
train_csv: train_standard.csv
```

## 第 3 步：安装依赖

Kaggle Notebook 中运行：

```bash
pip install segmentation-models-pytorch albumentations opencv-python-headless
```

如果 Kaggle 不能下载 ImageNet 预训练权重，把配置里的：

```yaml
encoder_weights: imagenet
```

改成：

```yaml
encoder_weights: null
```

## 第 4 步：先跑 Debug

```bash
python scripts/train.py --config configs/debug.yaml
```

你要看到类似输出：

```text
数据统计：total=..., defect=..., empty=...
使用设备：cuda
epoch=1 train_loss=... val_loss=... val_dice=...
最佳模型已保存：outputs/debug_smoke_test/best_model.pth
```

如果 Debug 报错，不要继续 Baseline。先把报错发给组长或记录下来。

## 第 5 步：跑 Baseline

```bash
python scripts/train.py --config configs/baseline.yaml
```

输出目录：

```text
outputs/baseline_unet_resnet34/
├── best_model.pth
├── config.yaml
├── history.csv
├── history.png
└── val_predictions/
```

这些文件都要保存，后续报告/PPT 会用。

## 第 6 步：生成 Kaggle 提交

```bash
python scripts/infer.py \
  --config configs/baseline.yaml \
  --checkpoint outputs/baseline_unet_resnet34/best_model.pth \
  --output outputs/baseline_unet_resnet34/submission.csv
```

上传 `submission.csv` 到 Kaggle，记录 Public Score。

## 第 7 步：把结果同步给 04

同时发：

## 02 数据分析对 03 的影响

02 已经发现类别不平衡：

- Class 2 样本最少，Baseline 可能漏检。
- Class 3 样本最多，模型可能偏向多数类。

所以 Baseline 之后再考虑：

- `configs/full_pipeline.yaml`
- `configs/ablations/no_augmentation.yaml`
- `configs/ablations/no_scheduler.yaml`
- 按类别阈值或 loss 权重调整

但第一轮先不要改复杂策略，先拿到 Baseline。

## 常见问题

### 训练很慢

检查 Kaggle 是否开启 GPU：

```text
Notebook Settings -> Accelerator -> GPU
```

### 显存不足

把配置里的 batch size 调小，例如：

```yaml
batch_size: 4
```

### 权重下载失败

把：

```yaml
encoder_weights: imagenet
```

改成：

```yaml
encoder_weights: null
```

### submission 尺寸问题

当前推理代码会把 debug 小尺寸 mask 恢复到原始尺寸；正式 baseline 默认就是 `256x1600`。
