## 环境安装

Kaggle Notebook 中通常已有 PyTorch，只需要：

```bash
pip install segmentation-models-pytorch albumentations opencv-python-headless
```

如果在本地跑，请优先用 Python 3.10 或 3.11。本地只建议 debug，不建议完整训练。

## 先跑 Debug

```bash
python scripts/train.py --config configs/debug.yaml
```

Debug 只用于检查流程，不代表最终效果。

## 跑 Baseline

```bash
python scripts/train.py --config configs/baseline.yaml
```

输出位置：

```text
outputs/baseline_unet_resnet34/
├── best_model.pth
├── config.yaml
├── history.csv
├── history.png
└── val_predictions/
```

## 生成提交文件

```bash
python scripts/infer.py \
  --config configs/baseline.yaml \
  --checkpoint outputs/baseline_unet_resnet34/best_model.pth \
  --output outputs/baseline_unet_resnet34/submission.csv
```

把 `submission.csv` 上传 Kaggle 后，把分数同步给实验汇报负责人和项目统筹。

## 需要跑的实验

| 实验 | 配置 | 目的 |
|---|---|---|
| Baseline | `configs/baseline.yaml` | 得到第一组可复现结果 |
| Full Pipeline | `configs/full_pipeline.yaml` | 验证完整方案是否优于 Baseline |
| w/o Augmentation | `configs/ablations/no_augmentation.yaml` | 配合 02 解释数据增强贡献 |
| w/o Scheduler | `configs/ablations/no_scheduler.yaml` | 验证学习率调度贡献 |

## 注意事项

- Kaggle 如果不能下载 ImageNet 预训练权重，把配置中的 `encoder_weights: imagenet` 改为 `encoder_weights: null`。
- 不要只发一张截图，要保留 `history.csv`、`history.png`、预测图和配置文件。
- 如果显存不足，先减小 batch size。
- 如果训练很慢，先确认是否打开 GPU。
- 如果改了输入尺寸，要确认推理提交时 mask 会恢复到原始尺寸。
- 本地 MacBook 不建议完整训练。
