# 答辩问题清单

> 目标：3 分钟答辩中回答要短、准、有依据。每个答案尽量指向实验表、配置文件、图表或可视化结果。

## 赛题与数据

| 可能问题 | 回答要点 |
|---|---|
| 为什么选择 Severstal 这个竞赛？ | 工业缺陷检测有实际价值；任务是语义分割；直接对应 CNN、U-Net、迁移学习、数据增强、评价指标等课程内容。 |
| 这个任务为什么不是普通分类？ | 输出不是单个类别，而是每张图 4 类缺陷的像素级区域，需要预测 Mask 并转为 RLE。 |
| 数据中最大的挑战是什么？ | 缺陷区域小、类别不平衡、部分图片无缺陷、RLE 标注需要正确解码。 |
| 评估指标 Dice 代表什么？ | 衡量预测 Mask 与真实 Mask 的重叠程度，越高表示分割区域越接近标注。 |

## 方法与模型

| 可能问题 | 回答要点 |
|---|---|
| 为什么选 U-Net + ResNet34 作为 Baseline？ | U-Net 是经典分割结构，ResNet34 预训练 Encoder 能在有限算力下提供稳定特征，复杂度适中。 |
| BCE Loss 和 Dice Loss 为什么组合使用？ | BCE 关注像素级分类，Dice 更贴近最终重叠指标，组合后兼顾局部像素和整体区域。 |
| 数据增强为什么有效？ | 钢板纹理和缺陷位置存在变化，适度翻转、旋转和亮度扰动能提升泛化，但增强过强可能破坏缺陷特征。 |
| 学习率调度的作用是什么？ | 前期保持学习效率，后期降低学习率让模型更稳定收敛，减少震荡。 |

## 实验与消融

| 可能问题 | 回答要点 |
|---|---|
| 消融实验如何保证公平？ | 使用同一数据划分、随机种子、评价指标和训练平台，每次只改变一个关键变量。 |
| 完整方案相比 Baseline 提升来自哪里？ | 用消融结果回答：数据增强贡献看 E0 vs E2，调度贡献看 E0 vs E3，完整方案看 E0 vs E1。 |
| 如果某个优化没有提升，如何解释？ | 说明可能原因，如训练轮数不足、增强过强、阈值未调好、验证集波动，并保留失败尝试作为反思。 |
| 为什么至少做 4 组实验？ | 课程要求至少 3 组；4 组能更清楚拆分关键组件贡献，也可争取消融实验加分。 |

## 智能体使用

| 可能问题 | 回答要点 |
|---|---|
| 智能体具体帮了什么？ | 协助项目规划、代码结构、RLE/Dataset 实现思路、消融设计、Prompt 迭代、报告材料整理。 |
| 如何避免智能体生成错误代码？ | 用单元测试、小样本 debug、阅读关键逻辑、对照 Kaggle 格式要求，不直接相信未验证输出。 |
| Prompt 迭代有什么例子？ | 从笼统要求改为加入评分标准、算力约束、输出格式、测试要求，得到更可执行的方案。 |
| AGENTS.md 有什么价值？ | 统一智能体工作规则和项目约束，减少生成内容偏离课程要求或改动范围。 |
