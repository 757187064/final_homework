Kaggle kernel-only 提交通常要求：

```text
Internet Off
```

如果训练或推理依赖联网下载 HuggingFace 权重、ImageNet 预训练权重、第三方依赖或在线模型文件，则最终 Save Version 或提交可能失败。

因此需要保留：

- 已下载好的模型权重；
- 可离线运行的 inference notebook；
- 格式正确的 `submission.csv`；
- 必要时使用 Small U-Net 离线保底版本。

### 4. 实验解释风险

当前 Kaggle 分数显示：

```text
No Augmentation / Baseline > Full Pipeline
```

因此不能简单写“增强越强效果越好”。

更合理的解释是：

```text
在当前设置下，强数据增强可能破坏钢板缺陷的细长纹理特征，导致 Kaggle 泛化结果下降。
后续优化应采用更精细的数据增强、类别阈值调优和类别不平衡处理。
```
