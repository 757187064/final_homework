## 如何生成数据分析图

进入模型代码文件夹：

```bash
cd ../03_模型训练与代码实现
python3 scripts/analyze_data.py --data-root data/raw --output-dir outputs/data_analysis
```

在 Kaggle Notebook 中运行时，数据路径通常是：

```bash
python scripts/analyze_data.py \
  --data-root /kaggle/input/severstal-steel-defect-detection \
  --output-dir outputs/data_analysis
```

输出文件：

```text
outputs/data_analysis/
├── class_distribution.csv
├── class_distribution.png
└── sample_masks.png
```

## 报告文字模板

```text
Severstal 数据集由钢板表面图像和对应缺陷标注组成。训练标注存储在 train.csv 中，每条记录由 ImageId_ClassId 和 EncodedPixels 构成，其中 EncodedPixels 使用 RLE 格式表示缺陷区域。每张图像最多对应 4 类缺陷，因此项目中将原始表格整理为一张图片对应 4 个类别 Mask 的形式。

从类别分布看，数据存在明显类别不平衡，并且部分图像没有缺陷。该特点会使模型更容易偏向预测背景，因此训练中采用 Dice Loss 与 BCE Loss 组合，并通过数据增强提升模型泛化能力。数据增强包括翻转、轻微旋转、亮度和对比度扰动等，用于模拟钢板图像采集中的位置和光照变化。
```
