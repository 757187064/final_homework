| 检查项 | 结论 |
|---|---|

## 可直接放进报告的文字

```text
Severstal 数据集由钢板表面图像和对应缺陷标注组成。训练标注存储在 train.csv 中，包含 ImageId、ClassId 和 EncodedPixels 三列。EncodedPixels 使用 RLE 格式表示缺陷区域，空值表示对应类别无缺陷。每张图像最多对应 4 类缺陷，项目中通过 pivot 操作将原始表格整理为一张图片一行、4 个类别各一列的形式。

训练集共 6,666 张钢板图片，所有图片均包含至少一种缺陷。4 类缺陷分布极不均衡：Class 3 样本最多（5,150 张，占 77.3%），Class 1 和 Class 4 居中（分别 897 和 801 张），Class 2 样本最少（仅 247 张，占 3.7%），与 Class 3 相差约 21 倍。这种类别不平衡会使模型更倾向于预测多数类，对小类缺陷的召回率较低。因此在训练中采用 BCE Loss 与 Dice Loss 组合损失函数，并通过数据增强提升模型泛化能力。数据增强包括水平翻转、轻微旋转、平移缩放和亮度对比度扰动等，用于模拟钢板图像采集中的位置和光照变化。
```

## 发现的问题

- **Class 2 样本极少**（仅 247 张），可能导致模型对该类缺陷的学习不充分，预测时容易漏检。
- **所有图片均有缺陷**（无负样本），这意味着模型无法学习"正常钢板"的特征，可能在推理时对无缺陷钢板产生误检。
- **标签高度不平衡**：Class 3 占绝对多数（77.3%），可能主导损失函数，需要合适的损失函数设计（BCE + Dice 组合）。
- **数据列名格式差异**：本地的 `train.csv` 使用 `ImageId, ClassId, EncodedPixels` 分列格式，与 Kaggle 平台的 `ImageId_ClassId` 合并格式不同，已在代码中做了兼容处理。
